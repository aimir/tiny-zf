# Binary-tape implementation proof

The fixed target is `Machine308.Halts ↔ Source.Provable 1`. This directory
develops the implementation side of that statement. The ICS-to-ZF interpretation
is outside this target; the tape-to-source simulation is required.

Read the modules in this order:

| Module | Role |
| --- | --- |
| [Core](Core.lean) | Proves that head-relative infinite tapes perform exactly the literal integer-indexed machine steps. Defines finite execution, positive progress, symbolic scans, and a sound finite-checkpoint checker. |
| [Registers](Registers.lean) | Proves selection, increment, both decrement branches, return scans, and the ten register-address chains against the actual 308-state table. All register values are unbounded. |
| [Control](Control.lean) | Proves binary path arithmetic and dispatch. The no-eight-consecutive-zeros condition prevents the instruction path being mistaken for the left tape margin. |
| [Paths](Paths.lean) | Checks dispatcher paths and proves their register, break, continue, and halt contracts. A balanced transition lookup is proved equal to the literal table before use in certificate evaluation. |
| [Cycles](Cycles.lean) | Composes selector passes and primitive operations into complete instruction executions, preserving register values and accounting for pointer space. |
| [Simulation](Simulation.lean) | Proves that positive finite implementations preserve and reflect unbounded halting, including after a finite bootstrap prefix. |
| [Program](Program.lean) | Provides a sound finite graph checker, proves its unbounded tape simulation, and derives an unbounded space invariant from a checked startup prefix and global instruction bound. |
| [Candidate](Candidate.lean) | Generated certificate for all 6,741 instruction paths, their successors, and startup space. Literal row indices keep each kernel check local; the complete certificate has passed kernel checking. |
| [Bootstrap](Bootstrap.lean) | Imports proposed checkpoints for the 39,769-step initialization and checks them with the literal transition function. Generated by `formal/tools/generate.py`; no generator or execution log is trusted. |

All modules in this directory have compiled successfully. Bootstrap checks all
39,769 literal steps. `Candidate.initialized_iff` proves unbounded halting
equivalence between the initialized tape and the primitive register graph.
Its 6,741 rows include every branch target, and its 117-step startup prefix
establishes an invariant covering all later pointer-space requirements.

The certificate uses private batches within one file to bound elaboration
memory; each row is still checked individually with `decide +kernel`. The
current build uses one Lean worker thread and an 8 GiB per-process cap. No
native-computation axiom or external certificate-checking executable is trusted.

The [source implementation library](../Interpreter/README.md) supplies the next
layer: arithmetic, clause semantics, exact structured placements, and a checked
correspondence between the source and optimized instruction graphs. The [headline theorem](../../TinyZF.lean) composes the complete chain.

The local proof structure follows the register/tape decomposition in
[Jeffrey Ketchersid's Coq verification](https://github.com/jeff87654/busy-beaver/tree/4590f221f53151f2b7ca4e7895f1080197ec05c3/ZF/verify/393),
with a separately checked literal table, ten active registers, and this
candidate's eight-zero dispatch threshold. The coordinate-change argument also
uses the approach developed for this project's sibling Riemann-machine proof.
Neither external development is an axiom or a build dependency.
